# meperdienelmetro — mobile

Aplicación móvil de **meperdienelmetro** para Android e iOS.

## Objetivo V1

- React Native + Expo + TypeScript.
- Planificación offline de rutas de Metro CDMX y Metrobús CDMX.
- Menor tiempo / menos transbordos para Metro.
- Resultado paso a paso.
- Rutas recientes y favoritas en almacenamiento local.
- Base preparada para audio, mapas y futuras funciones online.

La web vive en `apps/web` y ambas aplicaciones comparten el modelo y los controladores de `packages/core`.

## Estado

En desarrollo. Desde la raíz del monorepo:

```sh
npm install
npm run dev:mobile
```
